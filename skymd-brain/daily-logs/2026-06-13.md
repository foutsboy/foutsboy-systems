## Big Insight This Week — Mashup Clips (from Pavin call)

Had a call with Pavin. The key shift: stop thinking in raw clips, start thinking in **mashup clips**.

Instead of hundreds of folders with hundreds of individual clips, you build one folder of categorized mashup clips — already lightly color graded and cut together:

- Running — all running clips in one
- Working — all office/desk content in one
- Working out — gym, lifting in one
- Track workouts — all in one
- Drone shots — all in one
- Etc.

This is the new organizational layer. Way faster to find what you need. When an editor needs running B-roll, they go to one place and pull from one file.

This replaces the folder-diving problem entirely.
